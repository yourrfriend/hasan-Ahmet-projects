# Eşya sistemi 2 — uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Üç katmanlı 10 eşya, oyuncu başına iki yuva, pasif iksir/vasiyet, hedefli kilit/pusula, kum saati, zar ve tartışmada
meydana düşen "ilk dokunan alır" paketi; maç sonunda kim ne kullandı açıklanır.

**Architecture:** Kurallar `game.js`'te saf (`setClock`/`setRnd` ile deterministik test); paket `tick` içinde yaşar, `P.paket`
herkese açık yalnız tür+sayı+süre, `R.g.paket` gizli; sunucu iki yeni mesaj (`esya`, `kap`) yönlendirir; veritabanı/RPC değişmez;
istemci çipleri, paket katmanı ve son ekran sütunu; `hikaye.js`/gazete yeni satırlar.

**Tech Stack:** Node `node:test`, Playwright e2e, mevcut `kontrol.sh`.

**Spec:** `docs/superpowers/specs/2026-10-26-kasaba-gecesi-esya-2-design.md` (v1: `…ilerleme-esya-design.md`)

## Global Constraints
- Dal `esya-2` (`ilerleme`'den). Her görev sonunda commit (İngilizce), `kontrol.sh` (istemci görevinde `--e2e`).
- Eşya modu kapalıyken oyun birebir aynı; mevcut 155 test + e2e değişmeden geçer (olay şeması testi yalnız yeni alanlarla büyür).
- Gizli bilgi `P`'ye girmez: `R.g.paket` (`keys, alanlar, zaman`) gizli; `P.paket={key,n,ends}` yalnız; `SECRET_KEYS`'e `paket`.
- Sabitler `game.js`'te: `ESYA` (10; `faz`, `nadir`, `hedef`, `pasif`), `ESYA_YUVA=2`, `KASA_ESYA={siradan:50,nadir:40,efsanevi:10}`,
  `PAKET={sans:0.6,sure:5000,nadirP:0.25,maxMac:3,uzat:30000}`; bedava havuz = sıradan + zar.
- Duyurular anonim ve spec 5.1 tablosundaki metinlerle; fiş hiçbir yerde adla yazılmaz.
- `index.html` satır içi `//` yorum yok; `KG_VER` istemci görevinde `2026-11-02a`.
- Hedefli eşya ziyaret değildir (spec 5.7.7); vasiyet 7. adımda toplanır (5.7.8); kilit Seri Katil/Bombacı'da sessiz etkisiz.

## Review Focus
1. Paket yarışı: üç `kap` aynı anda, 2 yuva → sunucu sırasına göre ilk ikisi; aynı kişiden ikinci `kap` tek sayılır; yuvası dolu
   oyuncu `false` ve yayın yok → Task 3 testleri.
2. Paket açıkken faz/oyun biter (`advance`, `checkWin` → end, `cancel`): `P.paket=null`, "kimse kapmadı" satırı bir kez → Task 3.
3. Hedefli eşya kenarları: kendi evi, ölü hedef, aynı gece ölen hedef (kilit yine `blocked`), hedef Seri Katil → sahibine normal not,
   `etki:'durduramadi'`, haber yine çıkar → Task 2.
4. Pasif öncelik: aynı gece Doktor + iksir + yelek → Doktor kurtarır, iksir harcanmaz; iki saldırı aynı gece → iksir ikisini de
   karşılar, bir kez harcanır → Task 2.
5. Eski istemci `act{esya:true}` ve `vote{esya:'fis'}` biçimleri: `act` yok sayar, `vote` v1 boolean kalır → Task 2.
